APAISE — paquet prêt à héberger

CONTENU
- index.html : votre jeu original, avec métadonnées d’application web ajoutées
- manifest.webmanifest : nom et comportement de l’icône d’accueil
- sw.js : cache hors ligne après le premier chargement réussi
- icon.svg : icône de base APAISE

INSTALLATION SUR IPHONE
1. Hébergez le contenu de ce dossier sur un hébergement web HTTPS (par exemple Netlify).
2. Ouvrez l’URL HTTPS du jeu dans Safari.
3. Touchez Partager > Sur l’écran d’accueil.
4. Si l’option est disponible, activez « Ouvrir comme app web », puis touchez Ajouter.

IMPORTANT
- Ce paquet n’est pas une application iOS signée et ne s’installe pas directement depuis le ZIP.
- L’hébergement HTTPS est nécessaire pour l’installation en tant qu’app web et le cache hors ligne.
- Le jeu a été conservé ; seules les métadonnées PWA et l’enregistrement du service worker ont été ajoutés.
- Le cache hors ligne se remplit lors du premier chargement réussi. Certaines fonctions qui nécessitent Internet peuvent toujours dépendre d’une connexion.
